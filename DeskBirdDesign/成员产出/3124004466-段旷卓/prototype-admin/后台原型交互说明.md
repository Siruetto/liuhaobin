# 后台原型交互说明（段旷卓 · 前端）

对应角色：前端。本文件定义后台管理五个视图的页面结构、交互与规则，与 `prototype/admin.html` 一致。

## 页面清单

| 页面 | 组成 | 关键交互 |
| --- | --- | --- |
| 仪表盘 | 4 统计卡片 + 提醒概览表 | 查看统计 |
| 提醒管理 | 搜索框 + 筛选 + 表格 | 搜索、按状态筛选、完成/删除 |
| 工具管理 | 工具表格 + 开关 | 启用 / 停用工具 |
| 设备管理 | 绑定表单 + 设备表 | 绑定新设备 |
| 记忆 / 日志 | 记忆列表 + 日志列表 | 删除记忆；查看操作日志 |

## 交互规则

1. 提醒管理：搜索按内容模糊匹配；筛选按"全部/进行中/已完成"；完成与删除即时刷新列表和仪表盘统计。
2. 工具开关：停用后对话不再调用该工具，已有数据保留；操作写入运行日志。
3. 设备绑定：编号与名称必填；设备离线时前端显示"离线"，桌面端降级为本地提醒。
4. 主题与前台一致：主色 #FF8C42、深棕侧边栏 #3B3229、绿色表示在线/启用。
