# 报时鸟 测试用例（邓家俊 · PM / 测试）

对应角色：测试。以下用例覆盖《需求分析文档》验收标准 A1～A9（A10 上线运行在部署阶段验证），
其中 TC-07、TC-08 对应 A6 工具调用的安全分支。可直接作为后续编码的测试依据。

| 编号 | 功能 | 输入 / 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 语音记日程 | 说"提醒我周五 22:00 交作业" | 日程面板出现该提醒 | 待测 |
| TC-02 | 到点提醒 | 到点（误差 ≤ 5 秒） | 弹窗 + 语音播报，内容一致 | 待测 |
| TC-03 | 再提醒 | 点"10 分钟后再提醒" | 10 分钟后再次播报 | 待测 |
| TC-04 | 周期提醒 | 说"每天 21:00 背单词" | 按天重复，可取消 | 待测 |
| TC-05 | 文字对话多轮 | "北京天气" → "那上海呢" | 第二次仍识别为问天气 | 待测 |
| TC-06 | 记忆 | "我叫刘浩彬" → "我是谁" | 回答"你叫刘浩彬"，重启后仍在 | 待测 |
| TC-07 | 工具安全 | 输入 `__import__("os")` | 拒绝执行，给出原因 | 待测 |
| TC-08 | 文件越界 | 写入 `../secret.txt` | 拒绝，提示只能用 workspace/ | 待测 |
| TC-09 | 断网可用 | 无 API Key 时对话 | 离线规则兜底，提醒与文字可用 | 待测 |

## 异常分支

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-11 | 语音识别失败 | 自动降级为文字输入，不中断流程 |
| TC-12 | 提醒内容为空 | 拒绝并提示"内容不能为空" |

执行方式：人工走查（原型阶段）+ 自动化单元测试（编码阶段）。编号与需求文档验收标准保持一致，避免口径不一。
