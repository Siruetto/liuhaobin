# 论文查重（个人项目）

给出原文和一份在原文上经过增删改得到的抄袭版论文，计算两者的重复率，
结果写入答案文件，精确到小数点后两位。

## 需求

- 从命令行接收三个绝对路径：论文原文、抄袭版论文、答案文件
- 答案文件中的内容是精确到小数点后两位的浮点数
- 只能读写命令行给出的这三个文件，不得访问网络
- 单次运行要在 5 秒内给出答案，内存占用不超过 2048MB

## 接口约定

```bash
python main.py <原文文件绝对路径> <抄袭版论文绝对路径> <答案文件绝对路径>
```

## 开发计划

1. **基本功能**：读文件 → 求最长公共子序列 → 写出重复率
2. **扩展功能**：GB18030 编码兼容、异常处理与退出码
3. **性能优化**：降低 LCS 的时间复杂度，满足 5 秒上限
4. **测试与规范**：单元测试、覆盖率统计、flake8 代码质量检查
