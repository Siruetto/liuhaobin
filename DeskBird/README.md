# 报时鸟（DeskBird）· 桌面语音助手

> 软件工程小组作业（智能体）· 团队项目第一次作业：团队展示 + 选题报告 + 需求分析

一句话介绍：放在书桌上的"报时鸟"——你说一句它记住，到点了它主动开口提醒你，
还能动手帮你查课表、记笔记、算个数。

它是上一版[办公小助手](../AgentProject)的升级：从"被动问答"变成"主动服务"。
