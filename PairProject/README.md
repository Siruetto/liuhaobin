# 小学四则运算题目生成器（结对项目）

## 运行环境

Python 3.6+，**只用标准库**（分数用标准库的 `fractions.Fraction`，不用浮点，
所以 1/3 + 1/6 一定算成 1/2 而不是 0.4999…）。
`requirements.txt` 里列的 `pytest` / `pytest-cov` 只是用来跑测试和看覆盖率的。

## 生成题目

```bash
python main.py -n 10 -r 10
```

- `-n` 题目个数
- `-r` 数值范围：题目里出现的自然数、真分数的分子和分母都小于 r。**这个参数必须给**，缺了程序会报错并打印帮助

结果写在当前目录下的两个文件里：

```
Exercises.txt   题目, 例如 "1. 1/2 + 2/3 ="
Answers.txt     答案, 例如 "1. 7/6", 也就是 1'1/6
```

## 批改题目

```bash
python main.py -e Exercises.txt -a Answers.txt
```

统计结果写入当前目录下的 `Grade.txt`：

```
Correct: 5 (1, 3, 5, 7, 9)
Wrong: 5 (2, 4, 6, 8, 10)
```

批改时会重新按题目算出标准答案再比对，所以答案文件里写成 `2/4`、`15/2`
或者 `7'1/2` 这种等价形式都算对。

## 输出格式

| 内容 | 写法 |
| --- | --- |
| 整数 | `3` |
| 真分数 | `3/5`（五分之三） |
| 带分数 | `2'3/8`（二又八分之三） |
| 运算符 | `+ − × ÷`，前后各有一个空格 |
| 题目行 | `1. 1/2 + 2/3 =` |

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `main.py` | 命令行入口，解析 `-n -r -e -a`，把各模块串起来 |
| `expression.py` | 表达式树：求值、输出成题目文本、以及判重用的规范形式 |
| `generator.py` | 随机造题，保证满足"不出现负数、除得真分数、运算符不超过 3 个、不重复" |
| `number_text.py` | 分数与文本（`3/5`、`2'3/8`）之间的转换 |
| `records.py` | `Exercises.txt`、`Answers.txt`、`Grade.txt` 三种文件的读写 |
| `grading.py` | 批改：按题目算标准答案，再和答案文件比对 |

## 运行测试

```bash
python -m pytest --cov=. --cov-branch --cov-report=term-missing tests -q
# 不装 pytest 也可以:
python -m unittest discover -s tests -t . -v
```

## 参数不对时的表现

| 情况 | 行为 |
| --- | --- |
| 缺 `-n` 或 `-r` | 打印"参数错误"和完整帮助，返回码 2 |
| 批改模式缺少 `-e` 或 `-a` | 同上 |
| 同时给了生成和批改的参数 | 同上 |
| 输入文件不存在 / 格式不对 | 打印错误信息，返回码 1 |
| `-r` 太小、凑不齐这么多不重复的题 | 打印提示建议把 `-r` 调大，返回码 1（不会死循环） |
