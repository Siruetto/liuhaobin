# 报时鸟 Alpha 冲刺提交检查清单

## 必须提交

- [ ] 博客园发布《报时鸟-冲刺计划》，开头包含课程、作业要求、团队名称、成员和目标。
- [ ] 博客园发布《报时鸟-冲刺总结》，开头包含同样信息。
- [ ] 冲刺总结附上冲刺计划的正式博客 URL。
- [ ] 冲刺总结附上 GitHub 仓库链接。
- [ ] 3 分钟 Vlog 已上传到可公开访问的位置，并在总结或现场材料中给出链接。
- [ ] `报时鸟-Alpha冲刺答辩.pptx` 已提交到 GitHub 仓库。
- [ ] `v0.1.0-alpha.1` 已创建 Git Tag 和 GitHub Release。

## 内容检查

- [ ] 冲刺计划包含前序工作总结、改进方案、每名成员实际工作和计划工作量。
- [ ] 冲刺总结回答计划是否实现、项目亮点和不足。
- [ ] 冲刺总结包含 7 名成员完成内容和实际工作量比例，合计 100%。
- [ ] 7 名成员过程体会均由本人填写或确认。
- [ ] Vlog 包含冲刺计划、每日日志重点和队友交流过程。
- [ ] 14 天站立会均有记录；缺席成员注明原因。
- [ ] PPT 包含分工、预期计划、实际进度、燃尽图、问题、架构、部署、测试和体会。

## 现场设备

- [ ] `python --version` 可用，版本不低于 3.8。
- [ ] 运行 `DeskBirdApp\verify_alpha.ps1`，26 个测试通过。
- [ ] 运行 `DeskBirdApp\run_alpha.ps1`，8765 端口可用。
- [ ] 浏览器允许本地页面语音播报。
- [ ] 麦克风可用；不可用时准备纯文字演示路线。
- [ ] Vlog 已复制到演示电脑，不依赖在线播放。
- [ ] PPT 中嵌入字体或使用演示电脑已有字体。
- [ ] 准备好免网络演示，不依赖天气 API 和大模型 API。

## 发布命令

在仓库根目录执行：

```powershell
git add DeskBirdApp AlphaSprint README.md .gitignore
git commit -m "feat: deliver DeskBird alpha sprint"
git tag -a v0.1.0-alpha.1 -m "DeskBird Alpha 0.1.0"
git push
git push origin v0.1.0-alpha.1
```

GitHub Release 标题使用 `v0.1.0-alpha.1`，说明直接粘贴 `release-notes-v0.1.0-alpha.1.md`。
