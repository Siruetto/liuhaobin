# 报时鸟 Alpha 版演示与复现

## 环境

- Windows 10/11
- Python 3.8 或更高
- Chrome 或 Edge
- 仅使用 Python 标准库与浏览器原生能力

## 一键验收

```powershell
cd liuhaobin\DeskBirdApp
.\verify_alpha.ps1
```

预期结果：

1. 26 个自动化测试全部通过。
2. 服务在 8766 端口启动。
3. 状态接口报告 10 个工具。
4. `1+1` 对话返回 `2`。
5. 脚本自动关闭验收服务。

## 正式演示

```powershell
cd liuhaobin\DeskBirdApp
.\run_alpha.ps1
```

浏览器打开 <http://127.0.0.1:8765>。

## 故障处理

- 语音识别无响应：改用文字输入，界面不会中断。
- 没有麦克风：直接使用建议问题。
- 端口占用：`python web_server.py --port 8877`。
- 需要清空演示数据：关闭服务后删除 `DeskBirdApp/data/deskbird.db`。
