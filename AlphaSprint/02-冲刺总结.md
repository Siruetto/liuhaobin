## 一、冲刺结果摘要

原计划的核心改进是把上一版“能说会做”的 Agent 升级为“能主动提醒”的可运行产品。Day 1 已把最关键的链路落地：

- 自然语言新增一次性、每日和固定间隔提醒。
- SQLite 保存提醒，服务重启后仍可读取。
- 到期扫描触发网页气泡，并调用浏览器语音播报。
- 保留原 9 个工具，增加课表查询，共 10 个。
- 浏览器语音识别失败时自动保留文字输入。
- 提供一键验收脚本，26 个自动化测试通过。

截至 Day 1，可以通过 `DeskBirdApp/verify_alpha.ps1` 和 `DeskBirdApp/run_alpha.ps1` 复现。

### 项目亮点

1. 提醒不是静态界面，而是真实的自然语言解析、数据库保存和到期事件。
2. 工具数量保持 10 个，提醒作为核心服务，避免为了功能数量堆工具。
3. 没有 API Key、没有外网和语音失败时，核心提醒仍可运行。
4. 用户能看到每次工具调用，产品行为可解释。
5. 一键验收脚本同时验证测试、服务启动和 API。

### 当前不足

1. 浏览器语音依赖浏览器能力，离线识别和播报质量还不稳定。
2. 设备页目前以桌面端和模拟状态为主，ESP32 尚需实机验证。
3. 提醒通知只在网页打开或值守服务运行时出现，还需要桌面常驻封装。
4. Day 1 以后的真实团队过程数据尚未发生，不能用计划数据代替总结。

## 三、问题与解决

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 页面原型存在但功能不可执行 | 原型只用前端状态模拟 | 增加真实 API、SQLite 和调度器 |
| 工具数量容易膨胀 | 提醒增删查改若都做成工具会超过 10 个 | 提醒作为核心业务，只保留课表查询为第 10 个工具 |
| 语音识别可能失败 | 依赖浏览器与网络 | 失败后保留文字输入，不阻塞核心链路 |
| 到期时间测试不稳定 | 直接等真实时间会拖慢测试 | 测试显式注入 `now`，覆盖周期重排 |
| PowerShell 中文 JSON 请求乱码 | 旧版 PowerShell 默认编码不一致 | 验收脚本改用 UTF-8 字节请求纯 ASCII 算式 |
| 14 天过程素材容易遗漏 | 最后集中补拍会失真 | 每天收 20-30 秒原始视频和一条日志 |
